# Archive

These are superseded or variant notebooks preserved for reference. They are **not** part of the active pipeline.

**Why these are here:**
- `_bkup` — backup copies of notebooks before modifications
- `_mets`, `_peptides`, `_glycan` — modality-specific variants (the canonical notebooks in `notebooks/` are parameterized to handle all modalities)
- `_mem_optimized`, `_new` — alternative implementations that were superseded

For the current active pipeline, see `notebooks/`.
